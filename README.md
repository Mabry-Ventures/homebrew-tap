# Mabry Ventures Homebrew tap

```sh
brew install --cask mabry-ventures/tap/thalia
```

**Thalia** is a native Mac app for agentic coding with Meta's Muse Code CLI: plan the work, approve each command, review the exact diff and ship the branch. Free; requires an Apple Silicon Mac on macOS 27. Thalia updates itself, so `brew upgrade` is only needed if you prefer Homebrew to manage it.

More at [usethalia.com](https://usethalia.com/).
